# MASTER PROMPT: "Kaarjoo" (کارجو), a local-first AI job application desktop app (macOS + Windows)

You are a principal engineer and design engineer. Build a production-quality, **local-first desktop app** for **macOS (Apple Silicon and Intel) and Windows 10/11** that:

1. Takes one or more files from the user (PDF, DOCX, DOC, ODT, RTF, TXT, images, scanned PDFs, LinkedIn PDF export), in English or Persian.
2. Extracts a complete, accurate, structured profile from them, and lets the user verify every field against its source.
3. Searches several reputable job sites for positions that fit that profile and the user's preferences.
4. Scores and explains every match.
5. Writes a tailored résumé, cover letter and answers to screening questions for each chosen job, using only true facts from the profile.
6. Opens the application forms in a real browser and fills them in, with the user approving before submission (or automatically, within limits the user sets).
7. Tracks every application on a dashboard.

**Hard constraint: no paid or keyed external APIs.** No OpenAI/Anthropic/Gemini APIs, no job-board APIs that need keys (Adzuna, JSearch, RapidAPI, etc.), no paid scraping or captcha services. All AI runs **on the user's machine**. Job data comes from public web pages the user's own browser can see. The app must work with zero monthly cost.

The UI must feel premium: calm, fast, precise and beautiful, on the level of Linear, Raycast or Arc. Treat design quality and accuracy as hard requirements, not polish for later.

Work in phases (section 12). Do not try to build everything at once. Before writing code, read this whole prompt, then reply with: your understanding, questions that truly block you, and the Phase 0 plan. Then proceed phase by phase.
